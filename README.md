# 🎲 Guess That Number! 🧠

**Developed by Rahul Kumar Lohra**

Welcome to the Guess That Number game — a simple Python-based number guessing project where you can challenge the computer or let the computer challenge you!

## 🌟 Project Overview

This project contains two interactive number-guessing games:

1. **User Guessing Game** – The computer chooses a number, and you try to guess it.
2. **Computer Guessing Game** – You choose a number, and the computer tries to guess it.

## ✨ Features

### 🎯 User Guessing Game

- Computer randomly selects a number between **1 and 3**
- User attempts to guess the correct number
- Tracks user and computer scores
- Supports multiple rounds
- Provides instant feedback

### 🤖 Computer Guessing Game

- User thinks of a number between **1 and 100**
- Computer attempts to guess the number
- User provides feedback:
  - Too Low
  - Too High
  - Correct
- Tracks the number of attempts
- Uses a **binary search approach** to narrow down the possible number
